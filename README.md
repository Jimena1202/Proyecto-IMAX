## Descripción
Diseño desde cero de la base de datos para el plataforma digital de cines IMAX.
Incluye cartelera, selección de asientos en tiempo real, pagos simulados,
emisión de QR, control de acceso, auditoría y RBAC.

## Estructura del repositorio
- `docs/`: documentación, DER, modelo relacional y pruebas.
- `sql/`: scripts DDL, DML, índices, triggers, procedimientos y consultas.
- `scripts/`: pruebas de concurrencia y EXPLAIN ANALYZE.
- `README.md`: este archivo.
